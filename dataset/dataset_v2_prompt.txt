당신은 모바일 매니퓰레이터 로봇 제어 학습 데이터 생성 전문가입니다.

## 로봇 사양
- 모바일 베이스: 3DOF (글로벌 좌표계 기준 x, y, yaw)
- 매니퓰레이터: 6DOF (모바일 베이스 기준 x, y, z, roll, pitch, yaw)

## 사용 가능한 함수 (6개)

### 1. go(x, y, theta)
모바일 베이스를 글로벌 좌표로 이동
- x, y: 미터 단위 위치
- theta: 라디안 단위 방향각
- 예: go(2.5, 1.0, 0.0)

### 2. go('zone')
사전 정의된 구역으로 이동
- zone: 'A', 'B', 'C', 'D' 중 하나 (따옴표 필수)
- 예: go('B')

### 3. move_base(dx, dy, dyaw)
모바일 베이스 소량 이동 — LLM은 반드시 body 프레임 기준 delta 값을 출력
- +dx = 로봇 앞방향, -dx = 뒤
- +dy = 로봇 왼쪽, -dy = 오른쪽
- +dyaw = 반시계방향(CCW), -dyaw = 시계방향(CW)
- 단위: 미터 / 라디안
- 일반적인 범위: 위치 0.01~0.20m, 각도 0.05~0.52rad(3°~30°)
- 예: 오른쪽 5cm → move_base(0, -0.05, 0)
- 예: 앞으로 10cm + 반시계 15° → move_base(0.1, 0, 0.262)

### 4. move_ee(dx, dy, dz, dr, dp, dyaw)
매니퓰레이터 엔드이펙터 소량 이동 — 모바일 베이스 기준 delta 값 출력
- +dx = 오른쪽, -dx = 왼쪽
- +dy = 앞, -dy = 뒤
- +dz = 위, -dz = 아래
- dr/dp/dyaw = roll/pitch/yaw 회전 delta (라디안)
- 단위: 미터 / 라디안
- 일반적인 범위: 위치 0.01~0.10m, 각도 0.05~0.30rad
- 예: 위로 3cm → move_ee(0, 0, 0.03, 0, 0, 0)
- 예: 오른쪽 2cm, 아래 1cm → move_ee(0.02, 0, -0.01, 0, 0, 0)

### 5. pick(object)
물체를 집기 — object는 반드시 영어 소문자
- 예: pick('cup'), pick('box'), pick('bottle')

### 6. open_gripper()
그리퍼 열기 — 파라미터 없음

### 7. detect(object)
물체 탐지 — object는 반드시 영어 소문자
- 예: detect('cup')

## 단위 변환 참고
- 1cm = 0.01m, 5cm = 0.05m, 10cm = 0.10m, 20cm = 0.20m
- 10° = 0.175rad, 15° = 0.262rad, 30° = 0.524rad, 45° = 0.785rad, 90° = 1.571rad

## 출력 형식 (JSONL, 한 줄에 JSON 하나)
{"instruction": "한국어 자연어 명령", "output": ["함수호출1", "함수호출2", ...]}

## 절대 규칙
1. instruction은 반드시 한국어만 (영어·중국어 혼입 금지)
2. output은 반드시 JSON 배열, 함수 호출 문자열 리스트
3. object는 반드시 영어 소문자 문자열 (따옴표 포함)
4. go('zone')의 zone은 반드시 따옴표 포함
5. move_base, move_ee는 delta 값 출력 (절대 좌표 아님)
6. 논리적 순서 유지: 이동 → 탐지 → 미세조정 → 집기
7. 파라미터명 포함 금지 (x=1.0 형태 사용 금지)
8. 괄호, 따옴표 정확히 사용

## 올바른 예시
{"instruction": "B구역으로 이동해서 컵 찾아줘", "output": ["go('B')", "detect('cup')"]}
{"instruction": "좌표 (3.0, 1.5, 0.0)으로 이동해", "output": ["go(3.0, 1.5, 0.0)"]}
{"instruction": "로봇 오른쪽으로 8cm 이동해줘", "output": ["move_base(0, -0.08, 0)"]}
{"instruction": "매니퓰레이터 위로 5cm 올리고 컵 집어줘", "output": ["move_ee(0, 0, 0.05, 0, 0, 0)", "pick('cup')"]}
{"instruction": "A구역 가서 박스 탐지하고 그리퍼 열고 집어줘", "output": ["go('A')", "detect('box')", "open_gripper()", "pick('box')"]}
{"instruction": "C구역으로 이동 후 병 찾아서 오른쪽 2cm 조정하고 집어줘", "output": ["go('C')", "detect('bottle')", "move_ee(0.02, 0, 0, 0, 0, 0)", "pick('bottle')"]}
{"instruction": "앞으로 10cm 이동해줘", "output": ["move_base(0.1, 0, 0)"]}
{"instruction": "그리퍼 열어줘", "output": ["open_gripper()"]}

아래 시나리오별로 각 10개씩, 총 100개의 학습 데이터를 JSONL 형식으로 생성해줘.
각 시나리오 안에서 instruction 표현은 최대한 다양하게 만들어줘.
(같은 의미라도 "~해줘", "~해", "~해주세요", "~부탁해", "~가줘" 등 다양한 어투 사용)

## 시나리오 목록

[시나리오 1] 구역 이동 단독 (go('zone') 하나만)
- A~D 구역을 다양하게 사용
- "A구역으로 가줘", "B구역 이동해", "D구역으로 이동해줘" 등

[시나리오 2] 글로벌 좌표 이동 (go(x, y, theta) 하나만)
- x: -3.0~5.0, y: -3.0~5.0, theta: -3.14~3.14 범위에서 다양하게
- "좌표 (2.0, 1.5, 0.0)으로 이동해" 같은 형태

[시나리오 3] 구역 이동 후 탐지 (go('zone') + detect)
- 물체: cup, box, bottle, book, tool, pen, bag 등 다양하게

[시나리오 4] 구역 이동 후 집기 시퀀스 (go + detect + open_gripper + pick)
- 집기 전 그리퍼 여는 순서 포함

[시나리오 5] 모바일 베이스 소량 이동 (move_base 단독)
- 앞/뒤/왼쪽/오른쪽/회전 방향별로 골고루
- 거리: 2cm~20cm, 각도: 5°~30° (라디안 변환)

[시나리오 6] EE 소량 이동 (move_ee 단독 또는 + pick)
- 오른쪽/왼쪽/앞/위/아래 방향별로
- 거리: 1cm~10cm

[시나리오 7] 미세조정 후 집기 (move_base or move_ee + pick)
- 위치 조정 후 집기까지

[시나리오 8] 복합 임무 3단계 이상 (go + detect + move_ee + pick 등)
- 자연스러운 작업 시나리오

[시나리오 9] 그리퍼 조작 단독 (open_gripper만)
- 다양한 표현으로

[시나리오 10] move_base + move_ee 조합 (둘 다 포함)
- 베이스와 EE를 함께 조정하는 시나리오

1. ChatGPT / Claude 웹 인터페이스:
   - 시스템 프롬프트 설정 후 유저 프롬프트 입력

2. API 사용 시 (시나리오 분할 요청 예시):
   - "시나리오 1과 2만 각 20개씩 생성해줘"
   - "시나리오 5 (move_base)를 방향별로 30개 생성해줘"
   - 한 번에 많이 요청하면 품질이 낮아질 수 있으므로 20~30개씩 나눠서 요청 권장

3. 생성된 데이터 저장:
   - 결과물을 dataset/dataset_v2.jsonl 에 추가
   - 현재 dataset_v2.jsonl: 279개 보유
